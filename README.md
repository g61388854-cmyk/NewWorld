# NewWorld — платформа взаимодействия переводчиков и специалистов юридической сферы

NewWorld — единая профессиональная платформа, объединяющая два направления:

1. **Реестр и поиск переводчиков** — каталог специалистов с поиском по языкам, специализации, квалификации, региону и доступности, а также механизм направления запроса на привлечение переводчика.
2. **Рабочий кабинет переводчика** — управление заказами, документами, календарём, финансами и профессиональной деятельностью.

Центральной функцией платформы является реестр и механизм привлечения специалистов. Кабинет переводчика, CRM и финансовые инструменты усиливают эту функцию и не конкурируют с ней по значимости.

Пользователями платформы выступают переводчики, следователи, дознаватели, судьи и уполномоченные сотрудники судов, адвокаты, сотрудники правоохранительных органов, сотрудники бюро переводов и администраторы платформы.

## Ключевые архитектурные принципы

- Публичный поиск специалистов отделён от служебной информации: возможность найти переводчика не даёт доступа к чужим заказам, документам и персональным данным.
- Каждое поле профиля переводчика раскрывается только той категории пользователей, которой специалист разрешил его показывать.
- Принадлежность к государственному органу или адвокатскому образованию подтверждается проверкой, а не выбором пункта в списке.
- Согласие переводчика в приложении не заменяет процессуального решения о назначении переводчика (ст. 59 УПК РФ и аналогичные нормы иных процессуальных кодексов).
- Безопасность закладывается на уровне архитектуры: изоляция рабочих пространств организаций, многофакторная аутентификация, журналирование, шифрование.

## Технологии

Next.js 15 (App Router, серверные действия), TypeScript, PostgreSQL 16, Prisma 6, Vitest.

## Локальный запуск

Требуются Node.js 22 и PostgreSQL 16.

```bash
npm install
cp .env.example .env            # указать DATABASE_URL и FIELD_ENCRYPTION_KEY (openssl rand -base64 32)
npm run db:migrate              # применить миграции
npm run db:seed                 # демонстрационные данные (вымышленные)
npm run dev                     # http://localhost:3000
```

Демо-аккаунты (пароль `demo-password-2026`):

| Адрес | Роль | Примечание |
|---|---|---|
| `admin@demo.newworld` | Администратор платформы | При первом входе требуется настроить двухфакторную аутентификацию |
| `investigator@demo.newworld` | Следователь, полномочия подтверждены | То же |
| `advocate@demo.newworld` | Адвокат, полномочия подтверждены | — |
| `pending@demo.newworld` | Дознаватель, заявка на рассмотрении | Направление запросов недоступно |
| `translator1@demo.newworld` … `translator3@demo.newworld` | Переводчики | Чеченский, аварский, английский и немецкий языки |

## Проверки

```bash
npm run typecheck   # проверка типов
npm test            # модульные тесты: правила доступа, раскрытие сведений, статусы запроса, TOTP
npm run build       # сборка
```

## Структура

| Путь | Назначение |
|---|---|
| `prisma/schema.prisma` | Модель данных |
| `prisma/migrations/` | Миграции; журнал действий защищён от изменения триггером PostgreSQL |
| `src/lib/policy.ts` | Роли, обязательность MFA, тайм-ауты сессий, уровни раскрытия сведений профиля |
| `src/lib/request-flow.ts` | Статусы запроса на привлечение и допустимые переходы |
| `src/lib/registry.ts` | Поиск по реестру с учётом уровня раскрытия |
| `src/lib/auth.ts`, `src/lib/totp.ts`, `src/lib/crypto.ts` | Сессии, TOTP, шифрование полей (AES-256-GCM) |
| `src/app/app/` | Кабинеты переводчика, заказчика и администратора |
