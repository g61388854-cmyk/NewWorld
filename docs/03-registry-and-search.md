# 3. Реестр переводчиков и поиск

## 3.1. Раздел «Найти переводчика»

Пункт «Найти переводчика» размещается в боковом меню кабинета заказчика сразу после «Рабочего стола» — это основная рабочая функция следователей, адвокатов и других заказчиков.

```
┌──────────────────────────────────────────────────────────────┐
│ Найти переводчика                                            │
│ Поиск специалистов по языку, квалификации и региону          │
│                                                              │
│ [ Язык ▼ ] [ Регион ▼ ] [ Специализация ▼ ]                  │
│ [ Дата и время ▼ ] [ Формат работы ▼ ]                       │
│ [ Дополнительные фильтры ]                       [ Найти ]   │
├──────────────────────────────────────────────────────────────┤
│ Найдено специалистов: N                                      │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ ФОТО  Имя Фамилия                    Проверенный профиль │ │
│ │       Чеченский ↔ Русский                                │ │
│ │       Устный и письменный перевод                        │ │
│ │       Юридическая специализация                          │ │
│ │       Регион: Чеченская Республика                       │ │
│ │       Доступность: уточняется                            │ │
│ │       [ Профиль ]               [ Запросить переводчика ] │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

На десктопе — список компактных карточек, на мобильных устройствах — вертикальная лента карточек, фильтры открываются в отдельном листе.

## 3.2. Фильтры

Основная строка содержит пять фильтров (язык, регион, специализация, дата и время, формат). Остальные раскрываются по кнопке «Дополнительные фильтры».

| Группа | Параметры |
|---|---|
| Язык | Исходный язык; целевой язык; направление перевода; двусторонний устный перевод |
| Регион | Страна; субъект РФ; город; готовность к выезду; дистанционная работа |
| Специализация | Уголовное, гражданское, административное судопроизводство; юридический, медицинский, технический перевод; личные документы; деловые переговоры; синхронный перевод; сурдоперевод |
| Формат работы | Письменный; устный последовательный; синхронный; дистанционное участие; очное участие; перевод с сохранением оформления |
| Доступность | Доступен сейчас; доступен в выбранную дату; срочное привлечение; готовность к выезду |
| Квалификация | Образование; сертификаты; подтверждённый опыт; подтверждённые языковые компетенции; дополнительная подготовка |
| Организационные параметры | Работа с физическими лицами, организациями, государственными учреждениями; условия оплаты; стоимость (если её отображение разрешено) |

Технические замечания:

- Языки хранятся по справочнику ISO 639-3 (покрывает языки народов России, в том числе чеченский `che`, ингушский `inh`, аварский `ava`); русскоязычные названия — отдельным справочником.
- Языковая пара хранится как направление `source → target` с признаком двусторонности; фильтр «чеченский ↔ русский» находит и двусторонние пары, и пары в обоих направлениях.
- Сурдоперевод — отдельный «язык» (русский жестовый язык, `rsl`), а не только специализация.
- Регион — по справочнику субъектов РФ; город — по справочнику населённых пунктов субъекта.
- Ранжирование выдачи: точное совпадение языковой пары → доступность в выбранную дату → уровень подтверждения → регион. Платное продвижение в выдаче для государственного сегмента не применяется.

## 3.3. Профиль переводчика

Профиль — профессиональное досье без закрытых персональных сведений.

**Шапка:** фото или аватар, имя и фамилия, статус подтверждения, языковые пары, основные специализации, регион, доступность, кнопка «Запросить переводчика».

**Вкладки:**

| Вкладка | Содержание |
|---|---|
| Обзор | Краткая профессиональная информация, направления деятельности, формат услуг |
| Языки | Языковые пары, направления, уровень владения, подтверждённые компетенции |
| Квалификация | Образование, сертификаты, дополнительная подготовка, опыт |
| Услуги | Письменный и устный перевод, сопровождение мероприятий, юридический перевод и др. |
| Доступность | Календарь доступных периодов, предпочтительный формат, срочное привлечение |
| Документы | Перечень подтверждающих документов и статус проверки каждого (без самих файлов) |

Паспортные данные, адреса и иные чувствительные сведения в профиле не публикуются ни на одном уровне видимости, кроме `private`.

## 3.4. Статусы подтверждения

Подтверждение личности, проверка документов и подтверждение квалификации — независимые проверки с собственными статусами:

| Статус | Значение |
|---|---|
| Профиль не проверен | Сведения указаны переводчиком и не проверялись |
| Личность подтверждена | Установлено соответствие владельца аккаунта указанному лицу |
| Документы проверены | Представленные документы об образовании и квалификации проверены на подлинность и соответствие |
| Квалификация подтверждена в установленном порядке | Компетенция подтверждена по процедуре, предусмотренной регламентом платформы |
| Профиль временно ограничен | Профиль скрыт из выдачи или ограничен по решению администратора |

Статус в карточке сопровождается пояснением: «Проверка платформы не заменяет решения уполномоченного лица о назначении переводчика».

Регламент проверки должен определить: перечень принимаемых документов, сроки рассмотрения, основания отказа, процедуру обжалования, периодичность обновления сведений и порядок отзыва статуса.
